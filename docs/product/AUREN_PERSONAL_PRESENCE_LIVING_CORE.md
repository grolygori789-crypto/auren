# AUREN — Personal Presence & Living Core

**Implementation note · Build 8 · 25 August 2026**

## Purpose

Build 8 improves the feeling that Auren is a living, personal product users can return to every day without adding account or cloud complexity.

## Living Core

The Today Core must not read as a static logo. Idle motion is deliberately perceptible within roughly one to two seconds: the free surface carries restrained slosh/inertia and the internal champagne-dominant material contains a subtle moving mineral-aqua vein. Interaction or a newly saved state may briefly increase motion before settling. Reduced Motion remains authoritative.

## Personal identity

A user may set a local display name. When present, Today uses the name in the time-aware greeting. No honorific or gender assumption is added.

A profile photo is optional. Selecting an image opens a local crop editor that supports:

- drag/pan positioning,
- zoom from minimum full-coverage framing up to 3×,
- circular preview matching the actual avatar presentation,
- reset, cancel and explicit save.

The resulting 512×512 image is compressed locally and stored in the existing IndexedDB profile record. This build does not upload the image, perform face recognition or use it for body analysis.

## Today hierarchy

After a daily check-in, Auren prioritizes meaning over editing:

1. State captured
2. Readable semantic observations
3. One Useful Move
4. Halo explanation
5. Body Context and deeper evidence

The edit-check-in control becomes a secondary action. Observation cards use direction-aware semantics so high stress is never presented as a positive state.

## Halo

Halo remains an explainable evidence instrument, not a health score. Build 8 reduces decorative weight and uses finer hairline orbits, micro-scale ticks, shorter luminous segments and restrained nodes. Segment meaning remains Body range, Daily state, Movement and Continuity, with evidence available in the Halo detail sheet.

## Trust

This build preserves the existing non-diagnostic model. Personalization changes presentation and continuity, not medical authority.
