# Auren Luxe Halo & Profile Identity — Build 7

## Purpose

Build 7 is a physical-device refinement pass focused on perceived material quality, information hierarchy and personal ownership. It does not change the Body Intelligence trust model.

## Core glass

The Auren Core must read first as highly transparent glass, not a bordered circle. Depth comes primarily from specular reflection, subtle perimeter refraction, contact shadow and the liquid itself. Heavy multi-ring outlines are prohibited.

## Auren Halo

Halo is an explainable visualization, not a score and not a progress meter. The live implementation uses two hairline orbits, four restrained luminous fragments and four state nodes for Body Range, Daily State, Movement and Continuity. Missing data remains visually incomplete. Strong/Excellent states may brighten the instrument but must never imply a medical clearance.

## Daily observation language

Raw 1–5 values remain provenance. The surface UI prefers semantic labels. Stress uses inverse desirability relative to sleep, energy, mood and movement; a higher stress value must never be styled as a positive state merely because the number is high.

## Profile photo privacy

Profile photos are optional. The selected image is processed entirely on-device in the browser: center-cropped to a square, resized to 384 × 384, compressed, and persisted in IndexedDB. Build 7 does not upload, classify, identify, infer body composition from, or otherwise analyze the photo.

## Product rule

Premium visual treatment may increase delight, but trust and clarity remain higher priority than spectacle.
