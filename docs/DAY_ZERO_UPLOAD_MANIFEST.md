## Day Zero rule
Only real, currently useful files belong in the repository.
No empty folders, `.gitkeep` placeholders, backup copies, ZIP archives, temporary exports, or duplicate versioned Master Plan files are included.

Future folders such as `src/`, `assets/`, `tests/`, and `scripts/` should be created only when their first real file is ready to be committed.
