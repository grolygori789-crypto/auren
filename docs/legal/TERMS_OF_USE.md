โค้ดต้นฉบับ เอกลักษณ์ภาพ การแสดงออกของ Core และ Halo การออกแบบอินเทอร์เฟซ งานเขียน งานแปล/โลคัลไลเซชัน เอกสาร การคัดสรรจัดวาง และเนื้อหาต้นฉบับอื่นของ Auren ที่กฎหมายให้ความคุ้มครอง อยู่ภายใต้กฎหมายทรัพย์สินทางปัญญาและประกาศลิขสิทธิ์/ทรัพย์สินทางปัญญา

Auren ไม่อ้างสิทธิ์ผูกขาดเหนือข้อเท็จจริงด้านสุขภาพ แนวคิดหรือสูตร BMI ข้อเท็จจริงทางวิทยาศาสตร์ ไอเดีย วิธีการ ระบบ ขั้นตอน งานสาธารณสมบัติ หรือทรัพย์สินของบุคคลที่สาม

## 13. Repository สาธารณะและการมองเห็นซอร์ส

การมองเห็นทางเทคนิคไม่เท่ากับใบอนุญาตเชิงพาณิชย์แบบไม่จำกัด หากซอร์ส Auren เปิดผ่านแพลตฟอร์มสาธารณะ อาจมีสิทธิ์เฉพาะแพลตฟอร์ม เช่น การดูหรือ fork ตามเงื่อนไขของแพลตฟอร์มนั้น สิทธิ์ดังกล่าวไม่ได้สร้างสิทธิ์เพิ่มเติมจาก Benedict Interactive ในการขาย sublicense ใช้เชิงพาณิชย์ หรือทำผลิตภัณฑ์ที่คัดลอกสาระสำคัญจากงานที่ได้รับความคุ้มครอง เว้นแต่ได้รับอนุญาตแยกต่างหาก

## 14. ความพร้อมใช้งาน การเปลี่ยนแปลง และ Early Access

Auren อาจถูกอัปเดต แก้ไข ออกแบบใหม่ จำกัด ระงับ หรือยุติ ฟีเจอร์ Early Access/ก่อนเผยแพร่เต็มรูปแบบอาจเปลี่ยนตามหลักฐาน ความต้องการผลิตภัณฑ์ กฎหมาย หรือข้อจำกัดทางเทคนิค

ไม่มีการรับประกันว่าฟีเจอร์ทุกอย่างจะคงอยู่ ใช้ได้บนทุกอุปกรณ์ ทำงานต่อเนื่อง หรือปราศจากข้อผิดพลาด

## 15. ไม่มีการรับประกันผลลัพธ์

เท่าที่กฎหมายอนุญาต Auren ให้บริการตามสภาพและตามที่พร้อมใช้งาน Benedict Interactive ไม่รับประกันว่าจะทำให้เกิดผลด้านสุขภาพ ฟิตเนส สุขภาวะ น้ำหนัก สมรรถนะ หรือผลลัพธ์อื่นตามที่คาดหวัง

ข้อความนี้ไม่ตัดสิทธิ การรับประกัน หรือความคุ้มครองผู้บริโภคที่กฎหมายห้ามตัดออก

## 16. ข้อจำกัดความรับผิด

เท่าที่กฎหมายอนุญาต ผู้ดำเนินการและผู้ทรงสิทธิที่เกี่ยวข้องไม่รับผิดในความเสียหายทางอ้อม โดยบังเอิญ พิเศษ สืบเนื่อง หรือเชิงลงโทษ อันเกิดจากการใช้/ไม่สามารถใช้ Auren การสูญหายของข้อมูลในเครื่อง การพึ่งพาการตีความที่ไม่ใช่ทางคลินิก หรือความขัดข้องของแพลตฟอร์มบุคคลที่สาม

ข้อจำกัดนี้ไม่มีผลในกรณีที่กฎหมายไม่อนุญาตให้ตัดหรือจำกัดความรับผิด รวมถึงสิทธิผู้บริโภคภาคบังคับและความรับผิดที่กฎหมายกำหนดว่าต้องคงอยู่

## 17. การสิ้นสุดสิทธิ์ใช้งานเมื่อมีการใช้ผิด

เท่าที่กฎหมายอนุญาต สิทธิ์ใช้งานแบบจำกัดอาจสิ้นสุดเมื่อผู้ใช้ฝ่าฝืนข้อกำหนดอย่างมีสาระสำคัญหรือใช้ทรัพย์สินที่ได้รับความคุ้มครองเกินสิทธิ์ที่ให้ สิทธิและหน้าที่ที่โดยสภาพต้องคงอยู่ยังคงมีผล

Auren ปัจจุบันไม่มีระบบบัญชี ข้อนี้จึงไม่ได้อ้างว่ามีความสามารถทางเทคนิคในการปิดการใช้งานอุปกรณ์ของบุคคลใดจากระยะไกล

## 18. การเปลี่ยนข้อกำหนด

เอกสารที่มีผลต่อผู้ใช้มี Legal Version แยกจาก Build ของแอป การเปลี่ยนแปลงสาระสำคัญเกี่ยวกับสิทธิ หน้าที่ หรือ data practice อาจบังคับให้รับทราบใหม่ ส่วนการแก้คำเล็กน้อยที่ไม่เปลี่ยนสาระอาจไม่ต้องทำเช่นนั้น

Legal Version 1.0.0 มีผลตั้งแต่ 28 สิงหาคม 2569 (2026)

## 19. กฎหมายที่ใช้บังคับและสิทธิภาคบังคับ

เท่าที่กฎหมายอนุญาต ข้อกำหนดนี้อยู่ภายใต้กฎหมายไทย โดยไม่ตัดสิทธิคุ้มครองภาคบังคับที่กฎหมายในถิ่นพำนักของผู้ใช้กำหนดว่าต้องคงอยู่

เมื่อฉบับแปลมีสาระต่างกัน ฉบับภาษาอังกฤษเป็นข้อความอ้างอิงเพียงเท่าที่ข้อกำหนดเรื่องภาษาดังกล่าวชอบด้วยกฎหมาย และไม่ตัดสิทธิด้านภาษาที่กฎหมายท้องถิ่นกำหนด

## 20. การแยกส่วน การไม่สละสิทธิ และกรอบเอกสารทั้งหมด

หากข้อใดเป็นโมฆะหรือบังคับใช้ไม่ได้ ข้ออื่นยังคงมีผลเท่าที่กฎหมายทำได้ การไม่บังคับใช้หรือบังคับใช้ล่าช้าไม่ได้หมายถึงสละสิทธิโดยอัตโนมัติ

ข้อกำหนดนี้ต้องอ่านร่วมกับนโยบายความเป็นส่วนตัว ประกาศลิขสิทธิ์และทรัพย์สินทางปัญญา ประกาศบุคคลที่สาม และใบอนุญาตซอฟต์แวร์แบบ proprietary

## 21. การติดต่อและข้อมูลอ่อนไหว

คำถามเกี่ยวกับการขออนุญาต IP ความเป็นส่วนตัว หรือกรอบกฎหมาย ควรติดต่อผ่านช่องทางทางการของ Benedict Interactive ที่เผยแพร่พร้อมผลิตภัณฑ์หรือ repository เมื่อมีการกำหนด

ห้ามโพสต์ข้อมูลสุขภาพส่วนบุคคล รูปโปรไฟล์ ประวัติเช็กอินส่วนตัว หรือข้อมูลอ่อนไหวอื่นลงใน public issue tracker หรือกระทู้สนับสนุนสาธารณะ
